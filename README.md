# Maktab maslahatçilari KPI tizimi

Maktab maslahatçilarining faoliyatini nazorat qiliş, ularga metodik yordam körsatiş va rağbatlantiriş uçun KPI baholaş tizimi (respublika, viloyat va tuman darajalari, 8 mezon — 100 ball).

**Namuna (demo) versiya:** https://bahrilloutamurodov.github.io/KPI-tizimi/

Demo versiyadagi barça ma'lumotlar soxta. Ular faqat foydalanuvçining öz brauzerida saqlanadi va boşqalarga körinmaydi.
